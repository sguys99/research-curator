# Research Curator Frontend

Next.js 14 App Router frontend for Research Curator.

## Local Development

```bash
pnpm install
pnpm dev
```

App runs at `http://localhost:3000` (API expected at `http://localhost:8000`).

## Commands

```bash
pnpm lint
pnpm test
pnpm build
pnpm start
```

## Environment

- `NEXT_PUBLIC_API_URL` (see `frontend/.env.local`)
- `NEXT_PUBLIC_ADMIN_EMAILS` (comma-separated, optional)
